This document defines the full homepage structure, content placement, UI direction, visual style, section order, CTA placement, responsive behavior and development notes for the Subsidy Gyaan website.
1. Homepage Goal
The homepage should immediately communicate that Subsidy Gyaan by Advait Associates is a trusted advisory platform for Central Government and Gujarat Government subsidy consultancy. It should build trust, explain the services clearly, show major schemes, educate visitors, and move users toward checking eligibility or contacting the team.
Item
Direction
Primary Goal
Generate consultation enquiries from entrepreneurs, MSMEs, industrial units, micro food processors, SHGs, FPOs and growing businesses.
Secondary Goal
Educate visitors about subsidy categories, DPR, registrations, documentation and advisory support.
Design Reference Mood
Use the clean, large, modern and light-theme feel of the Enviro-style reference, but convert it into a subsidy consultancy and business advisory identity.
Core Emotion
Knowledge, guidance, progress and prosperity. The line "Gyaan se Pragati, Salah se Samriddhi" should be used as the emotional backbone.

Performance Rule
Use optimized WebP images, lazy-load below-fold visuals, minimize JS and keep animations lightweight.
Accessibility Rule
Use readable contrast, visible focus states, semantic headings, labelled form fields and keyboard-friendly accordions.

8. Responsive Layout Rules
Desktop 1200px+: keep spacious two-column hero and 3-column service cards.
Laptop 992px-1199px: reduce hero heading size and keep cards in 3 columns or 2 columns depending on available width.
Tablet 768px-991px: stack hero content and visual, use 2-column service/industry grids.
Mobile under 767px: single-column layout, large tap-friendly buttons, accordion menus, no heavy animation.
Header on mobile should use a simple hamburger menu with clear CTA.
Keep brand line visible in hero and final CTA even on small screens.
9. Developer Build Notes
Build using HTML, CSS and vanilla JavaScript only.
Use reusable CSS classes for section labels, buttons, cards, grids, CTA blocks and accordions.
Use one main style.css and one main.js for homepage interactions.
Use JavaScript for mobile menu, sticky header class, FAQ accordion, scheme accordion and counter animation.
Keep the homepage modular so the same header/footer can be copied to all inner pages.
Avoid copying the reference template exactly. Use it only for spacing, modern light theme and section rhythm inspiration.
